# Мини-стенд одиночной проверки барьеров MIB-211 / MIB-212

Стенд для проверки, а при необходимости и калибровки, одного изделия MIB-211 / MIB-212
(плата MIB-212 Ex, КДСА.426475.001 Э3). Построен на основе программы **MIB_Calibrator**: те же
CA71, шлюз MK-531, алгоритм подбора коэффициента и шаблон протокола. Добавлен небольшой блок
коммутации на ESP32. Он подаёт питание на изделие и измеряет ток потребления, сам переключает
каналы 1 и 2, включает нагрузку 400 Ом и даёт кнопки СТАРТ/СТОП с индикацией ГОДЕН / НЕ ГОДЕН.

## Что изменилось по сравнению с MIB_Calibrator

| | MIB_Calibrator | Мини-стенд |
|---|---|---|
| Переключение каналов | вручную, провода CA71 перекидываются по сообщению программы | реле стенда, без участия оператора |
| Питание изделия | внешнее | от стенда, с измерением и нормой тока потребления, аварийным отключением |
| Точка «20 мА, 400 Ом» | не измерялась, в протокол шло значение 20 мА | измеряется на реальной нагрузке 400 Ом |
| Режимы | только калибровка | «Проверка» (коэффициенты не трогаются) и «Калибровка + проверка» |
| Самоконтроль | — | тракт стенда проверяется по CA71 без изделия |
| Учёт | протокол .xlsx | протокол .xlsx (если есть шаблон) + отчёт .csv + общий `Журнал_проверок.csv` |
| Безопасность | — | кнопка СТОП на стенде, сторожевой таймер связи с ПК, защита по току |

## Быстрый старт

Без оборудования, в имитации:

```bash
cd MIB_Stand/pc
pip install -r requirements.txt
python stand_gui.py
```

В окне поставьте галочку «Имитация», нажмите «Подключить», введите любой серийный номер и
нажмите СТАРТ. То же из консоли:

```bash
python stand_cli.py --simulate --serial TEST
```

На реальном стенде: прошить ESP32 (`docs/04_Наладка_стенда.md`), собрать блок по
`docs/01_Схема_стенда.md` и работать по `docs/03_Инструкция_оператора.md`. Шаблон протокола
MIB_Calibrator (`ШАБЛОН*.xlsx`) положите рядом с программой.

## Что нужно уточнить по ТУ

ТУ на изделие при разработке не было, нормы взяты из MIB_Calibrator:

* допуск 0,08 % от диапазона 16 мА, точки 0/4/8/12/16/20 мА и 20 мА на 400 Ом;
* **ток потребления 10…150 мА — предварительная норма**, её нужно заменить значением из ТУ (поля в
  окне, сохраняются в `stand.ini`);
* схема включения входа: активный источник (как в MIB_Calibrator) или 2-проводный датчик от
  питания изделия. Стенд поддерживает оба варианта тумблером «РЕЖИМ ВХОДА».

Если в ТУ есть другие проверки (например, напряжение питания датчика на клеммах +24 V1/+24 V2 или
работа при пониженном питании), их можно добавить в `check_logic.py`.
