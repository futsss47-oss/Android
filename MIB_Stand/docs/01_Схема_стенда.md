# Мини-стенд MIB-211 / MIB-212: схема и подключения

Стенд рассчитан на одно изделие: плата MIB-212 Ex (КДСА.426475.001 Э3) или одноканальная MIB-211.
Образцовым прибором остаётся **Yokogawa CA71**, а коэффициенты пишутся через **шлюз MK-531**, как в
MIB_Calibrator. Стенд добавляет:

* питание изделия +24 В с измерением тока потребления и аварийным отключением;
* автоматическое переключение каналов на реле, так что оператор больше не перекидывает провода CA71
  между каналами;
* настоящую нагрузку 400 Ом для точки «20 мА, 400 Ом» (в MIB_Calibrator эта точка не измерялась
  отдельно);
* нагрузку 249 Ом на неиспользуемом выходе;
* самоконтроль тракта стенда без изделия;
* кнопки СТАРТ и СТОП и индикацию ИДЁТ / ГОДЕН / НЕ ГОДЕН на передней панели.

Все переключения в токовых петлях последовательные, поэтому сопротивление контактов реле на
результат не влияет: ток в петле одинаков во всех её точках. Погрешность измерения стенда равна
погрешности CA71.

## 1. Структурная схема

```
 ПК (stand_gui.py) ──USB──► ESP32: реле K1–K6, INA226, кнопки, индикация
 ПК ──USB──► MK-531 ──SPI──► XP1 изделия (коэффициенты MCP4161)
 ПК ──RS-232/USB──► CA71

 ~220 В → БП 24 В → K5 → INA226 → кл.1–3 (питание изделия)
 CA71 ИСТОЧНИК → K1 / K2 → SA1 «АКТ / ПАСС» → кл.10–12 (вход 1) / кл.7–9 (вход 2)
 кл.4 / кл.5 (выходы) → K3 → [400 Ом, закорочен K4] → CA71 ИЗМЕРИТЕЛЬ mA → кл.6 GND_PLC
 невыбранный выход → K3 → 249 Ом → кл.6
 CA71 ИСТОЧНИК → K6 → тракт измерителя (самоконтроль без изделия)
```

## 2. Разъёмы изделия (по КДСА.426475.001 Э3)

| Разъём изделия | Конт. разъёма | Клемма изделия | Цепь | Куда на стенде |
|---|---|---|---|---|
| XP2 POWER (MSTBO 2,5/3-G1PR) | 1, 2 | 1, 2 | +24 V | шунт INA226 после K5 |
| | 3 | 3 | GND | 0 В БП 24 В |
| XP3 IOUT (MSTBO 2,5/3-G1PR) | 1 | 4 | CH1 → IOUT_1 | K3.1 НЗ, K3.2 НР |
| | 2 | 5 | CH2 → IOUT_2 | K3.1 НР, K3.2 НЗ |
| | 3 | 6 | GND_PLC | COM измерителя CA71, вывод R4 (249 Ом) |
| XP4 INPUT_1 (MSTBO 2,5/3-G1L BU) | 1 | 10 | +24 V1 (питание датчика, Ex) | SA1.1 положение «ПАСС» |
| | 2 | 11 | IN1 | SA1.1 «АКТ», SA1.2 «ПАСС» |
| | 3 | 12 | GND1 | SA1.2 «АКТ» |
| XP5 INPUT_2 (MSTBO 2,5/3-G1L BU) | 1 / 2 / 3 | 7 / 8 / 9 | +24 V2 / IN2 / GND2 | SA1.3 / SA1.4, как для XP4 |
| XP1 SPI (6 конт.) | 1–6 | — | +5V, CS2#, CS1#, SCK, SDI/SDO, GND | кабель MK-531, напрямую, стенд в эту цепь не входит |

На схемах ниже «кл.N» означает клемму изделия N.

Ответные части: MSTB 2,5/3-ST (шаг 5,0 мм), для XP4/XP5 синие (BU). Провода от стенда до ответных
частей длиной не более 0,5 м. Вместо отдельных проводов удобно сделать «косу» с маркировкой
XP2…XP5.

> Гальванические группы изделия разделены: GND (питание), GND_PLC (выходы), GND_Ex_1 и GND_Ex_2
> (входы). Стенд их **не объединяет**: входы коммутируются двухполюсными реле, а SA1 выбирает
> контакты внутри каждой группы отдельно. Не соединяйте между собой минусы CA71 и 0 В стенда.

## 3. Электрическая схема блока коммутации

### 3.1 Питание изделия и измерение тока

```
 БП +24 В ── FU1 0,5 А ──┬── K5 (НР) ──┬── R10 4,7 кОм ── HL4 «24 В ИЗД» ── 0 В
                         │             │
                         │             └── IN+ ─[ RS1 0,1 Ом ]─ IN−, VBUS ── кл.1, кл.2 изделия
                         │                 (INA226 измеряет падение на RS1)
                         └── DA2 R-78E5.0-0,5 ── +5 В: катушки реле, зуммер
 БП 0 В ──────────────────────────────────────────── кл.3 изделия, GND ESP32, GND INA226
```

INA226 питается от 3,3 В ESP32, адрес 0x40 (A0 и A1 на GND), SDA = GPIO21, SCL = GPIO22, подтяжки
4,7 кОм к 3,3 В. Ток потребления выше 300 мА прошивка считает аварией: снимает питание и шлёт
`EV OVERCURRENT`.

### 3.2 Вход изделия (источник CA71)

```
 CA71 ИСТ+ (Г1) ─┬─ K1.1 НР ── SA1.1 общ ─┬ «АКТ»  → кл.11 IN1
                 │                        └ «ПАСС» → кл.10 +24V1
 CA71 ИСТ− (Г2) ─┼─ K1.2 НР ── SA1.2 общ ─┬ «АКТ»  → кл.12 GND1
                 │                        └ «ПАСС» → кл.11 IN1
                 ├─ K2.1 НР ── SA1.3 общ ─┬ «АКТ»  → кл.8 IN2
                 │                        └ «ПАСС» → кл.7 +24V2
                 ├─ K2.2 НР ── SA1.4 общ ─┬ «АКТ»  → кл.9 GND2
                 │                        └ «ПАСС» → кл.8 IN2
                 └─ K6.1 / K6.2 НР — самоконтроль, см. 3.4
```

* **АКТ** (активный вход, как в MIB_Calibrator): на CA71 функция источника **4-20mA**, CA71 сам
  выдаёт ток в IN относительно GND канала.
* **ПАСС** (имитация 2-проводного датчика): на CA71 функция **20mA SINK**, петлю питает
  +24 V канала изделия. Так заодно проверяется питание датчика.

Прошивка всегда сначала размыкает один вход, потом замыкает другой, поэтому источник никогда не
бывает подключён к двум каналам одновременно. Программа ПК перед любым переключением выключает выход
CA71, то есть реле коммутируют без тока.

### 3.3 Выход изделия (измеритель CA71) и нагрузка

```
 K3.1: общий → точка A;                НЗ → кл.4 CH1;   НР → кл.5 CH2
 K3.2: общий → R4 249 Ом → кл.6;       НЗ → кл.5 CH2;   НР → кл.4 CH1

 точка A ──┬── R1 200 Ом ── R2 200 Ом ──┬── точка B ── CA71 ИЗМ mA+
           └──── K4.1 НЗ ∥ K4.2 НЗ ─────┘
                                            CA71 ИЗМ COM ── кл.6 GND_PLC
```

* K3 выключено: CH1 идёт на измеритель, CH2 на нагрузку 249 Ом. K3 включено: наоборот.
* K4 выключено: контакты закорачивают R1+R2. Измеритель включён в петлю напрямую, как в
  MIB_Calibrator. K4 включено: в петлю последовательно с CA71 входит **400 Ом** (точка «20 мА,
  400 Ом»).
* Падение напряжения при 20 мА на 400 Ом равно 8 В. Выходной каскад XTR111 + BSP170P питается от
  12 В, запаса хватает.

### 3.4 Самоконтроль (K6), только без изделия

```
 CA71 ИСТ+ ── K6.1 НР ── точка A (перед нагрузкой)
 CA71 ИСТ− ── K6.2 НР ── кл.6 GND_PLC
```

Источник CA71 замыкается на измеритель CA71 через тот же тракт: контакты K3 и K4, R1+R2, провода.
Программа сверяет заданный и измеренный ток (4, 12, 20 мА и 20 мА + 400 Ом). Прошивка запрещает
K6 при включённом питании изделия или подключённом входе.

### 3.5 ESP32 DevKitC: назначение выводов

| GPIO | Назначение | Подключение |
|---|---|---|
| 25 | K1 IN1 | ULN2003A вход 1 |
| 26 | K2 IN2 | ULN2003A вход 2 |
| 27 | K3 OUT (канал 2) | ULN2003A вход 3 |
| 14 | K4 LOAD 400 Ом | ULN2003A вход 4 |
| 13 | K5 PWR изделия | ULN2003A вход 5 |
| 18 | K6 SELF | ULN2003A вход 6 |
| 4 | HL1 жёлтый «ИДЁТ» | через 330 Ом |
| 16 | HL2 зелёный «ГОДЕН» | через 330 Ом |
| 17 | HL3 красный «НЕ ГОДЕН» | через 330 Ом |
| 19 | HA1 зуммер | NPN BC817 (база через 1 кОм), зуммер от +5 В |
| 32 | SB1 «СТАРТ» | кнопка на GND, подтяжка внутренняя |
| 33 | SB2 «СТОП» | кнопка на GND, подтяжка внутренняя |
| 21 / 22 | I2C SDA / SCL | INA226 |

GPIO12 не используется, потому что это вывод выбора напряжения флеш-памяти при старте. GPIO 6–11
заняты флеш-памятью. Катушки реле питаются от +5 В (DA2), общий провод ULN2003A на 0 В. Вывод COM
ULN2003A (9) подключён к +5 В: там встроенные диоды гашения.

Кнопка СТОП работает и без ПК: прошивка сразу выключает все реле, включая питание изделия.
Сторожевой таймер связи (команда `WDT`, программа ставит 30 с) обесточивает изделие, если программа
на ПК зависла или кабель USB выдернут.

## 4. Протокол обмена ESP32 ↔ ПК

USB-COM, 115200 8N1, строка заканчивается `\n`. Полный список команд приведён в шапке
`firmware/src/main.cpp`. Основные команды:

| Команда | Ответ | Действие |
|---|---|---|
| `ID?` | `OK MIB-STAND,1.0` | опознание (по нему программа ищет стенд на COM-портах) |
| `ROUTE 1` / `ROUTE 2` | `OK` | вход и выход канала на CA71, нагрузка 400 Ом выключена |
| `LOAD 0/1` | `OK` | нагрузка 400 Ом |
| `PWR 0/1` | `OK` | питание изделия |
| `I?` | `OK 62.3 24.01` | ток потребления, мА, и напряжение, В |
| `SELF 0/1` | `OK` / `ERR …` | самоконтроль |
| `ALLOFF` | `OK` | всё выключить |
| (без запроса) | `EV START`, `EV STOP`, `EV WDT`, `EV OVERCURRENT` | события |

Проверить стенд вручную можно из любого терминала (PuTTY, монитор порта Arduino) или командой
`python stand.py --port COM5 state`.

## 5. Конструкция

* Корпус: пластиковый, на DIN-рейку или настольный, примерно 200×150×70 мм. На передней панели:
  SB1, SB2, HL1–HL4, SA1 «РЕЖИМ ВХОДА: АКТ / ПАСС», гнёзда 4 мм «ИСТОЧНИК CA71 + / −» (красное /
  чёрное) и «ИЗМЕРИТЕЛЬ CA71 mA / COM».
* Плата коммутации: макетная или односторонняя. Цепи петель 20 мА разводятся отдельно от цепей
  +24 В и катушек. Между группами входа 1, входа 2 и выхода должно быть не менее 3 мм.
* На крышке или ложементе: место под плату (4 стойки по крепёжным отверстиям), «коса» с ответными
  частями XP2–XP5 и маркировкой, кабель MK-531 к XP1.
* Шильдик: «Стенд проверки MIB-211/212. Без изделия не включать K5. Самоконтроль только без
  изделия».
