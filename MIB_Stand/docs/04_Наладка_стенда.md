# Наладка и периодический контроль стенда

## 1. Прошивка ESP32

1. Установите VS Code и расширение PlatformIO (или PlatformIO Core: `pip install platformio`).
2. Откройте папку `firmware`, подключите ESP32 по USB и выполните:

```bash
pio run -t upload
```

3. Проверка в мониторе порта (`pio device monitor`, 115200): на `ID?` должен прийти ответ
   `OK MIB-STAND,1.0`.

## 2. Проверка коммутации без CA71 (мультиметр)

Удобнее всего через блок «Ручное управление (наладка)» в окне программы или командами вида `python stand.py --port COM5 in 1` (в таблице указана только последняя часть: `in 1`, `load 1`...):

```bash
python stand.py --port COM5 state
```

| Действие | Что измерить | Норма |
|---|---|---|
| всё выключено | гнездо «ИСТ+» ↔ кл.11 (тумблер АКТ) | обрыв |
| `in 1` | «ИСТ+» ↔ кл.11, «ИСТ−» ↔ кл.12 | < 1 Ом |
| `in 1` | «ИСТ+» ↔ кл.8 | обрыв |
| `in 2` | «ИСТ+» ↔ кл.8, «ИСТ−» ↔ кл.9; «ИСТ+» ↔ кл.11 | < 1 Ом; обрыв |
| `out 1`, `load 0` | кл.4 ↔ гнездо «ИЗМ mA» | < 1 Ом |
| `out 1`, `load 1` | кл.4 ↔ гнездо «ИЗМ mA» | 400 Ом ± 0,5 Ом |
| `out 1` | кл.5 ↔ кл.6 | 249 Ом |
| `out 2` | кл.5 ↔ «ИЗМ mA»; кл.4 ↔ кл.6 | < 1 Ом; 249 Ом |
| `pwr 1` | напряжение кл.1 – кл.3 | 24 В, горит «24 В ИЗД» |
| `self 1` (без изделия) | «ИСТ+» ↔ «ИЗМ mA»; «ИСТ−» ↔ кл.6 | < 1 Ом |
| всё выключено | сопротивление между группами «вход 1», «вход 2», «выход», «питание» (мегаомметр 500 В) | > 20 МОм |

## 3. Ток потребления

Подключите заведомо исправное изделие, включите питание (`pwr 1`) и сравните показания
`python stand.py --port COM5 supply` с амперметром в разрыве +24 В. Расхождение должно быть не больше
1 мА. Если больше, поправьте `SHUNT_OHM` в `firmware/src/main.cpp` под фактическое сопротивление шунта.

Нормы тока потребления (поля «Ток потребл. от/до» в окне) установите по ТУ. Ориентир — значения
трёх-пяти заведомо исправных изделий плюс-минус 20 %.

## 4. Самоконтроль и метрология

* **Самоконтроль** (кнопка в окне, без изделия) выполняйте в начале каждой смены. Он проверяет
  связь с CA71, тракт реле и включение 400 Ом: источник CA71 должен иметь достаточное
  напряжение, чтобы прогнать 20 мА через 400 Ом.
* Погрешность стенда определяется CA71. Стенд содержит только последовательные элементы токовой
  петли, поэтому сам погрешности не вносит. CA71 должен быть поверен.
* **Раз в месяц** проверяйте мультиметром сопротивление нагрузки (п. 2, `load 1`: 400 Ом ± 0,5 Ом)
  и то, что при `load 0` она закорочена. Залипание K4 самоконтроль не обнаружит: ток в петле от этого
  не меняется.
* Контрольный образец: держите одну проверенную плату MIB-212 с записанными в журнал результатами
  и раз в неделю проверяйте её в режиме «Проверка». Результаты должны совпадать в пределах
  ±0,01 %.

## 5. Работа без оборудования

Программу можно запустить в режиме **«Имитация»** (галочка в окне или `python stand_cli.py
--simulate --serial TEST`). В этом режиме имитируются стенд, CA71 и шлюз, и имитатор CA71
«видит» ток только при правильной коммутации реле. Так удобно обучать операторов и проверять
изменения в программе.
