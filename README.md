# Сверхурочные

Android-приложение, которое в фоне следит за вашей геопозицией относительно места работы, считает время сверхурочной и сумму к оплате по вашей формуле. Все данные хранятся только на телефоне, никакого сервера нет.

## Как это работает

1. В «Настройках» вы нажимаете «Назначить место работы здесь и сейчас» (находясь на работе) и задаёте график.
2. Приложение регистрирует геозону. Система сама будит приложение, когда вы приходите на работу или уходите.
3. Пока вы на работе, запускается фоновый сервис (значок в шторке) и раз в 10 минут (настраивается) берёт геопозицию.
4. Когда наступает время сверхурочной, открывается запись. Она закрывается, когда два замера подряд оказались вне зоны. Время окончания ставится по последнему замеру на работе.
5. Один «выброс» геолокации не считается уходом: если следующий замер снова на работе, запись продолжается.
6. Если вы вышли (например, в магазин) и вернулись в течение заданного времени (по умолчанию 60 минут), запись продолжается, а время отсутствия засчитывается.
7. Сумма считается по вашей формуле отдельно за каждый день, за месяц суммируется.

### Что можно настроить
- график по дням недели (начало, конец, выходной);
- режим: «только после смены» или «до начала и после конца»; допуск после конца смены; все ли выходные часы сверхурочные;
- округление (шаг, вниз/вверх/до ближайшего) и минимальный порог за день;
- радиусы входа (100 м) и выхода (200 м), порог точности замера, интервал опроса;
- формулу оплаты.

### Формула оплаты
Пример по умолчанию (первые 2 часа ×1,5, дальше ×2, выходной ×2):

```
if(weekend, rate * h * 2, rate * (min(h, 2) * 1.5 + max(h - 2, 0) * 2))
```

Переменные: `h` (часы за день), `m` (минуты), `rate` (ставка ₽/час), `salary` (оклад), `norm` (норма часов в месяце), `weekend` (1 в выходной), `dow` (1–7).
Функции: `min`, `max`, `abs`, `round`, `floor`, `ceil`, `sqrt`, `pow`, `if(условие, да, нет)`. Дробные числа пишутся через точку. Формула вычисляется собственным безопасным разборщиком, а не `eval`.

Примеры: `salary / norm * 1.5 * h`, `rate * h * if(dow >= 6, 2, 1.5)`.

### Ручной режим
На главном экране кнопка «Начать/Закончить сверхурочную вручную». На вкладке «Месяц» можно добавить запись задним числом, исправить или удалить любую. Ручные и исправленные записи считаются как есть, без обрезки по графику.

## Сборка

1. Установите Android Studio (Ladybug или новее) с JDK 17+.
2. Откройте папку проекта (`OvertimeTracker`) и дождитесь синхронизации Gradle.
3. Подключите телефон по USB с включённой отладкой и нажмите Run, либо `Build → Build APK(s)`.

Версии плагинов указаны в `build.gradle.kts` и `app/build.gradle.kts`. Если Android Studio предложит обновления, их можно принять.

### Тесты логики
Вся логика расчёта находится в модуле `domain` (чистый Kotlin, без Android):

```
./gradlew :domain:test
```

## Первый запуск на Samsung

1. Выдайте доступ к геолокации, затем «Разрешать всегда» (Android откроет страницу настроек).
2. Разрешите уведомления (иначе значка фонового режима не будет видно).
3. «О приложении → Батарея → Без ограничений».
4. «Настройки → Батарея → Ограничения в фоновом режиме»: отключите автоматическое усыпление неиспользуемых приложений и уберите приложение из «Спящих».

## Структура

```
domain/   чистый Kotlin: окна сверхурочной, округление, формулы, движок учёта, тесты
app/      Android: база Room, геозона, фоновый сервис, экраны на Jetpack Compose
```

## Известные ограничения
- Место работы задаётся кнопкой по текущей позиции (карты нет). Координаты можно уточнить, нажав кнопку ещё раз, стоя в нужной точке.
- Одно место работы.
- Праздничные дни не определяются автоматически: пометьте нужный день недели выходным в графике или добавьте запись вручную.
- Геозоны Android срабатывают с задержкой в 1–3 минуты, внутри зданий GPS неточен. Поэтому опрос и подтверждение двумя замерами, а на случай сбоев есть ручная правка.
- Приложение проверено только юнит-тестами логики. На реальном телефоне оно пока не запускалось.
