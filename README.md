# Учёт пациентов

Android-приложение для учёта основных и диагностических пациентов и контроля сроков анализов. Данные хранятся зашифрованными на телефоне, между своими телефонами синхронизируются через вашу папку на Яндекс Диске.

## Возможности

- **Вход по PIN-коду** (4–8 цифр) и, по желанию, по отпечатку. Блокировка, если приложение свёрнуто больше минуты. После 5 неверных попыток пауза. В списке недавних приложений содержимое скрыто, скриншоты запрещены.
- **Главный экран:** «Основные пациенты», «Диагностические пациенты», «Сроки и напоминания», поиск по всем пациентам, настройки.
- **Списки:** поиск по ФИО (без учёта регистра и «ё»), добавление, удаление с подтверждением. У каждого пациента видно ближайший срок, просроченные выделены красным.
- **Основной пациент:**
  - «Учёт»: ФИО, дата рождения, телефон, адрес, номер карты, дата взятия на учёт, основной диагноз, несколько сопутствующих диагнозов, напоминания.
  - «Лечение»: начало интенсивной фазы и начало фазы продолжения.
- **Диагностический пациент:**
  - «Явка»: личные данные, дата первой явки, жалобы, напоминания.
  - «Что сделать» и «Результат»: свободный текст.
  - Кнопка «→» в шапке переводит пациента в основные, данные явки сохраняются и видны в блоке «Из диагностики».
- **Напоминания:** несколько на пациента, название, дата и время, повтор (каждые N дней, недель, месяцев), предупреждение заранее, отметка «выполнено». У повторяющегося напоминания после отметки срок переносится на следующий.
- **Уведомления** с ФИО пациента, в том числе на экране блокировки. Кнопка «Выполнено» прямо в уведомлении. Срабатывают при закрытом приложении и после перезагрузки.
- **Синхронизация через Яндекс Диск:** при входе, при сворачивании приложения и по кнопке. Слияние по каждой записи: побеждает более свежая правка, удаление тоже переносится.
- **Резервная копия** в файл, зашифрованный паролем. При восстановлении данные объединяются с текущими.

## Установка APK

1. Откройте репозиторий на GitHub → вкладка **Actions** → последний запуск **Build APK** в ветке `patients`.
2. Внизу страницы в разделе **Artifacts** скачайте `patients-debug-apk` (zip с файлом `app-debug.apk`).
3. Распакуйте и установите на телефон (разрешите установку из этого источника).

Новые сборки ставятся поверх старых с сохранением данных (постоянный ключ подписи `app/debug.keystore`).

## Первый запуск

1. Придумайте PIN-код.
2. Разрешите уведомления.
3. «Настройки → Уведомления»: все три строки должны быть с галочкой. На Samsung дополнительно: «Настройки телефона → Приложения → Учёт пациентов → Батарея → Без ограничений».
4. Нажмите «Проверить: уведомление через 1 минуту», заблокируйте экран и дождитесь уведомления.

## Настройка Яндекс Диска (один раз)

1. Войдите на https://oauth.yandex.ru в свой аккаунт Яндекса и нажмите «Создать приложение».
2. Название любое, например «Учёт пациентов». Платформа: «Веб-сервисы», Redirect URI: `https://oauth.yandex.ru/verification_code`.
3. Доступы: «Яндекс Диск REST API → Доступ к папке приложения на Диске».
4. Скопируйте **ClientID** созданного приложения.
5. В приложении «Настройки → Синхронизация»: вставьте ClientID, нажмите «Войти в Яндекс». В браузере разрешите доступ и скопируйте показанный токен.
6. Вставьте токен, придумайте пароль синхронизации (от 6 символов) и нажмите «Сохранить и синхронизировать».
7. На втором телефоне повторите шаги 5–6 с тем же ClientID и **тем же паролем синхронизации**.

Файл лежит в «Приложения/<название приложения>/patients.sync» на вашем Диске и зашифрован паролем синхронизации: Яндекс его содержимое не видит.

## Сборка

GitHub Actions собирает APK на каждый пуш в ветку `patients` (`.github/workflows/build-apk.yml`). Локально: Android Studio, JDK 17, открыть папку проекта.

```
./gradlew :core:test :app:assembleDebug
```

## Структура

```
core/   чистый Kotlin: модели, слияние для синхронизации, повторы напоминаний, шифрование паролем, тесты
app/    Android: зашифрованное хранилище (Android Keystore), будильники и уведомления,
        Яндекс Диск, экраны на Jetpack Compose
```

## Безопасность

- База `store.bin` зашифрована AES-256-GCM ключом из Android Keystore. Токен Яндекса и пароль синхронизации тоже.
- PIN хранится только как хэш PBKDF2 с солью.
- Файлы синхронизации и резервных копий: AES-256-GCM, ключ из пароля через PBKDF2 (120 000 итераций).
- Данные исключены из облачных копий Google.
- Если PIN забыт, его не восстановить: «Забыли PIN?» стирает данные на телефоне, после чего их можно вернуть с Яндекс Диска.

## Ограничения

- Если один и тот же пациент правился на двух телефонах между синхронизациями, остаётся более поздняя правка всей карточки.
- Приложение проверено юнит-тестами логики. На реальном телефоне его нужно проверить.
