# MIB-252 Ex — диагностическая прошивка

Плата КДСА.426475.003, МК STM32L052K8T6. Прошивка проверяет два входа АЦП
(AD7792 через мосты SC18IS602B) и два выхода ЦАП (DAC8750) и показывает
результат на светодиодах «CH1» и «CH2». USB не используется.

Готовый файл: `MIB252_diag.hex` (адрес 0x08000000, заливается через SWD, XP3).
Штатная прошивка при этом стирается — для возврата залейте `MIB252_v30.hex`.

## Что подключить

- **Вход** (XP1 / XP2): резистор 100 Ом (или Pt100) между `+IN` и `-IN`.
  Допустимо 5…650 Ом.
- **Выход** (XP4, `CH1`/`CH2` относительно `GND_RPP`): миллиамперметр или
  резистор до ~250 Ом. Ток на обоих выходах меняется ступенями
  **4 → 12 → 20 мА**, каждая ступень 3 с.

## Индикация

При старте — три поочерёдные вспышки CH1/CH2 (прошивка запущена).
Далее каждый светодиод относится к своему каналу:

- **горит постоянно** — вход и выход канала исправны;
- иначе повторяется: пауза 1 с → **короткие** вспышки (код АЦП) →
  **длинные** вспышки (код ЦАП).

| Коротких | Вход АЦП |
|---|---|
| 1 | мост SC18IS602B не отвечает по I2C (изолированное питание канала, изолятор CPC5902, мост) |
| 2 | AD7792 не отвечает: неверный ID, не читается регистр, нет готовности |
| 3 | внутренний контур не в норме: источник тока AD7792, ключи TS5A3154, R7, R8 |
| 4 | обрыв входа — ток возбуждения не проходит через `+IN`/`-IN` |
| 5 | короткое замыкание входа (< ~5 Ом) |
| 6 | сопротивление на входе выше диапазона (> ~650 Ом) |

| Длинных | Выход ЦАП |
|---|---|
| 1 | `ALARM` активен при выключенном выходе — неисправность DAC8750 или его цепей |
| 2 | `ALARM` активен при включённом выходе — обрыв токовой петли / слишком большая нагрузка (либо перегрев) |

## Как проверяется

АЦП, по порядку (первая же ошибка становится кодом):
1. настройка моста (адреса 0x29 — CH1, 0x2A — CH2);
2. сброс AD7792 и чтение ID;
3. ток 20 мкА через R7 → R8, измерение напряжения на R8 (канал AIN3,
   внутренняя опора) — контур целиком внутри платы;
4. то же через внешние клеммы — обнаружение обрыва;
5. измерение сопротивления на входе (опора — R8, 2×210 мкА, усиление 8).

ЦАП: импульс CLR, диапазон 0–24 мА; сначала проверяется `ALARM` при
выключенном выходе, затем выходы включаются и `ALARM` контролируется
на каждой ступени тока.

Ограничение: чтение регистров DAC8750 по SPI не используется (штатная
прошивка его тоже не использует), поэтому «ЦАП не принимает команды» напрямую
не определяется. Косвенный признак: при **отключённой** нагрузке должен
появиться код «2 длинных»; если светодиод продолжает гореть, а тока на
выходе нет — ЦАП команды не принял.

## Сборка

```bash
make
```

Нужен `arm-none-eabi-gcc`. Тактирование — HSI 16 МГц, сторожевой таймер IWDG
перезапускается (на случай, если он включён option-байтами).
